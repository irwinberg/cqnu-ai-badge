# 积分提醒站

| 文件 | 作用 |
|---|---|
| `模板/index.html` | 网页本身（单文件）。顶部三段 JSON（站点设置 / 工具介绍 / 积分活动）是唯一需要改的地方 |
| `自动领取.py` | 进阶：电脑每天自动领（WorkBuddy 签到、RunningHub、魔搭社区） |
| `工牌提醒.py` | 把“今天要领的”推送到自己的 AI 工牌 |
| `SKILL.md` | 本说明 |

先判断用户要哪一种，只做那一部分：

- “做积分提醒站 / 我也要一个” → 第 1–3 步，然后第 4 步选提醒方式
- “提醒我每天领积分” → 直接第 4 步
- “帮我设置积分自动领取” → 第 6 步
- “更新积分活动” → 第 5 步

运行 Python 脚本时：Mac 用 `python3`；Windows 或没有 Python 的电脑，用 WorkBuddy 自带的
`~/.workbuddy/binaries/python/versions/current/bin/python3`（Windows：`%USERPROFILE%\.workbuddy\binaries\python\versions\current\python.exe`）。

## 第 1 步：问清三件事（一次问完，用户没说就用默认）

1. 网站叫什么？默认“我的 AI 积分提醒站”
2. 提醒哪些工具？默认 WorkBuddy、RunningHub、豆包、DeepSeek
3. 每天几点提醒？默认 09:00

## 第 2 步：生成用户自己的网页

1. 把 `模板/index.html` 复制到用户工作目录下的 `我的积分提醒站/index.html`（文件夹里只放这一个文件）
2. 只改 `id="config"` 那段 JSON：`站名`、`提醒时间`、`显示的工具`，其余不动
3. 用户要加模板里没有的工具：在 `id="tools"` 加一项，在 `id="deals"` 按同样字段加活动（见第 5 步规则）
4. 改完检查 JSON 合法（逗号、引号），在浏览器打开预览一遍

## 第 3 步：发布成链接

优先用 **活页**（WorkBuddy 自带，发出来的页面在微信里能直接打开，还能推送到微信）：把 `我的积分提醒站/index.html` 发布成页面，把小程序码和链接给用户。
没有活页时，用 WorkBuddy 的网页发布把文件夹发布成静态网站。

## 第 4 步：每天提醒（让用户选，可多选）

- **微信晨报（推荐，不用开电脑）**：用活页给第 3 步的页面建一个晨报任务（`notify` 的 `report_task`）：每天提醒时间自动更新这一页并推送到用户自己的微信。任务要求写成：
  > 读取页面里 `id="deals"` 的积分活动，按今天日期列出“每天都能领”和 3 天内截止的限时活动，标题写“今天可领 N 项”，每项附官方链接；不要上网搜索，不要改动活动数据。

  先 `trial` 试跑一次给用户看，确认后再启用。告诉用户：晨报每次运行会用一点 WorkBuddy 积分，在积分明细里能看到。
- **手机日历（人人可用）**：手机打开网页 → “每天提醒我” → “加到手机日历” → 添加
- **AI 工牌·不用开电脑**：让用户在工牌上进“设置 → 我的消息”，用微信扫码，在打开的网页里打开“每天积分提醒”、选时间、保存。之后由服务器每天推送
- **AI 工牌·自己写（动手版）**：先请用户把“我的消息”网页的地址发给你（形如 `http://118.24.193.151/m/xxxxxxxxxx`，叫“我的链接”），然后：
  ```bash
  python3 工牌提醒.py --网页 我的积分提醒站/index.html --试一下                     # 先看推送内容
  python3 工牌提醒.py --网页 我的积分提醒站/index.html --我的链接 <我的链接>          # 发到自己的工牌
  ```
  确认工牌响了，再建一个 WorkBuddy 定时任务，每天提醒时间运行第二条命令。没有 Python 时，用“我的消息”网页最下面“给 WorkBuddy 用”里的 curl 命令，效果一样。

  规则：“我的链接”只能给用户自己的工牌发提醒，不要写进网页、不要发到群里。**不要使用课堂口令**（那是老师上课用的）。

## 第 5 步：更新积分活动（用户说“更新一下积分活动”时）

逐条打开 `id="deals"` 里每一项的“链接”，核对数量、规则、截止时间：
- 有变化就改；活动结束就删掉这一条（或把“截止”改成已过的日期，网页会自动隐藏）
- 把“来源”改成“X月X日核实官方页面”，`config` 里的“数据更新”改成今天
- 改完重新发布（第 3 步），链接不变

**收录规则**（新增活动时必须遵守）：
- 只收平台官方公开的活动，“链接”必须是官方页面
- 不收：邀请码 / 邀请链接、返利、共享账号、二手积分、API 中转站、要先充值的
- 只在社区文章里看到、找不到官方原文的，可以收，但必须加 `"待确认": true` 并在“来源”写清楚

活动字段：`id`（英文短名，唯一）、`工具`、`周期`（每天 / 限时 / 新人 / 长期免费）、`标题`、`数量`、`说明`、`链接`、`来源`，可选 `截止`（YYYY-MM-DD）、`待确认`、`按钮`（按钮文字）、`连签奖励`（如 [7,14,28]）、`自动`（true：能被 `自动领取.py` 领取）、`图标`。

## 第 6 步：电脑每天自动领（进阶，用户说“帮我设置积分自动领取”时）

能自动领：WorkBuddy（打开客户端即签到）、RunningHub（每日登录 30 积分）、魔搭社区（每日登录 200 魔粒）。豆包、DeepSeek 没有每日积分，不用自动领。

1. **检查环境**：`python3 自动领取.py 检查`
   - 没有 agent-browser：用 WorkBuddy 自带的 npm 安装 `npm i -g agent-browser --registry=https://registry.npmmirror.com`（Mac：`~/.workbuddy/binaries/node/versions/current/bin/npm`）。不用运行 `agent-browser install`：脚本会直接用电脑上的 Chrome 或 Edge
2. **本人登录一次**（每个网站一次，会弹出浏览器窗口）：
   ```bash
   python3 自动领取.py 登录 runninghub
   python3 自动领取.py 登录 modelscope
   ```
   告诉用户：“请在弹出的窗口里登录（扫码或验证码），登录好后不用关窗口，我这边会自动检测。”**不要替用户输入账号密码**
3. **试领一次**：`python3 自动领取.py 运行`，把结果念给用户
4. **每天定时**：`python3 自动领取.py 定时 09:00`（时间按用户说的）。说明：每 10 分钟检查一次，过了设定时间、当天还没领就去领；那时电脑没开的，开机后会补领；取消用 `定时 关`
5. **领完告诉工牌（可选）**：有工牌的，请用户发来“我的链接”，运行 `python3 自动领取.py 设置 --我的链接 <我的链接>`，以后每天领完工牌会响一声，显示“自动领了 N 项积分”
6. 以后用户问“今天领了吗”：读 `~/.points-reminder/今天.json` 回答；某个网站显示“要登录”，就带用户重新做第 2 步

规则：登录信息只存在本机 `~/.points-reminder/browser-profile`，不要复制、上传、打包，不要读取里面的 cookie；不要改脚本去调用平台的私有接口或批量账号。

## 注意

- 网页上的“领到了”只记在用户自己手机的浏览器里，不上传、不同步
- 不保存任何账号密码；自动领取只在用户本人电脑上、用本人已登录的浏览器完成
