# 重师大 AI 工牌：分步配置向导

你在带一位不熟悉电脑操作的老师配置 AI 工牌。整个流程 5 步，约 10 分钟。

## 怎么带

- **一次只讲一步。** 每一步只告诉用户这一步要做的 1–3 个动作，然后停下来，等用户回复“好了”或者描述屏幕上看到的东西，再进入下一步。不要把 5 步一次全贴出来。
- 每一步开头写“第 N 步 / 共 5 步：标题”，让用户知道进度。
- 话要短，用大白话，不说“端口”“固件分区”“命令行”这类词。需要运行的命令你自己运行，不要让用户去敲。
- 用户说看到的画面和下面写的不一样，先按“常见问题”处理；处理不了就请他拍照发给培训老师。
- 本技能目录下文简称 `<技能目录>`，运行命令时换成实际的完整路径（路径里有空格或中文时加引号）。

## 第 1 步 / 共 5 步：把工牌插到电脑上

告诉用户：
1. 用**能传数据的 USB-C 线**把工牌插到电脑上（有的线只能充电，不行就换一根）。
2. 按一下工牌侧面的任意键，让屏幕亮着。
3. 好了就回复“好了”。

用户回复后，你运行检查（只读，不会改动工牌）：
- Mac：`bash "<技能目录>/flash-mac.command" --check`
- Windows：`powershell -NoProfile -ExecutionPolicy Bypass -File "<技能目录>\flash-windows.ps1" -Check`

看输出最后一行：
- `RESULT=OK`：告诉用户“工牌连上了”，进入第 2 步。
- `RESULT=FAIL`：把上面那句“【没成功】……”换成大白话告诉用户，按提示处理后重新检查。

## 第 2 步 / 共 5 步：刷入重师大固件

先告诉用户：“现在开始刷机，大约 3–5 分钟。第一次会先自动备份原厂固件。**这段时间别拔线、别动工牌。**”然后直接运行：
- Mac：`bash "<技能目录>/flash-mac.command"`
- Windows：`powershell -NoProfile -ExecutionPolicy Bypass -File "<技能目录>\flash-windows.ps1"`

命令要跑几分钟，等它结束再看结果：
- `RESULT=OK`：告诉用户“刷好了，工牌会自动重启，屏幕上会出现重师大的开机画面”，请他看一眼确认，然后进入第 3 步。
- `RESULT=FAIL`：按提示处理（多数是拔线重插、让屏幕亮着），再运行一次同一条命令。第二次会跳过备份直接写入。工牌不会因为刷失败而坏掉。

## 第 3 步 / 共 5 步：给工牌连 Wi-Fi

工牌只支持 **2.4G** Wi-Fi，名字带“5G”的不行。在家、在会场都可以，只要这个 Wi-Fi 能上网。

告诉用户：
1. 手机先连上要用的 Wi-Fi，打开手机**蓝牙**。
2. 在微信里搜索小程序 **「蓝牙配网-FoloToy AI PASSPORT」**，打开。
3. 在设备列表里选 **BLUFI_FoloPassport**，选 Wi-Fi、输入密码，提交。
4. 等工牌屏幕显示连上（大约半分钟），回复“好了”。

工牌开机后连不上 Wi-Fi 时，会自动打开蓝牙等手机来配。如果小程序里找不到设备：让用户在工牌上进“设置”→“重新连 Wi-Fi”，按确定键，再搜一次。

连上之后，工牌会自动去找后台，大约 1 分钟内会出现下面两种画面之一：
- “这张工牌还没有登记”（第一次用都是这个）：进入第 4 步。
- 已经显示名字和主页（以前登记过）：跳到第 5 步。

## 第 4 步 / 共 5 步：扫码登记姓名和身份

告诉用户：
1. 工牌屏幕上用**上 / 下键**把金色框移到“**扫码登记**”，按**确定键**，屏幕上会出现一个二维码。
2. 用手机微信或飞书扫这个二维码，填姓名、身份（学员选“学生”，老师选“教师”）、班级或单位，再选一个喜欢的头像，提交。
3. 半分钟内工牌会显示你的名字。如果让你选身份，用上下键选好，按确定键。看到主页就回复“好了”。

## 第 5 步 / 共 5 步：收一条测试消息

请用户报一下工牌码：在工牌上进“设置”，屏幕下方“工牌码”后面的 6 位字母数字就是。
读取 `<技能目录>/server.txt` 第一行得到后台地址（下文记作 `<后台>`），然后打开这个网址（用 curl，或者直接在浏览器里打开都行）：

```
<后台>/api/v1/hello?code=<工牌码>
```

返回里有 `"ok":true` 就是发出去了。问用户工牌有没有亮屏、响一声、整页显示“新消息：欢迎使用 AI 工牌”（按任意键关闭）。

- 收到了：恭喜用户配置完成，再用两三句话教他用法：
  - 上下键移动金色框，确定键进入。
  - 按住确定键 1.5 秒回主页。
  - 想改名字或头像：进“设置”→“我的资料”，再扫一次码。
  - 想给同学发消息、设每天积分提醒：进“设置”→“我的消息”，用微信扫码。
- 返回“工牌码不对”：让用户再核对一遍 6 位码。
- 返回“发过几次了”：每小时最多发 3 次，看看工牌是不是已经收到了。

## 其他请求

| 用户想要 | Mac | Windows（在 flash-windows.ps1 后面加） |
|---|---|---|
| 升级到新版本（保留 Wi-Fi 和登记） | `bash "<技能目录>/flash-mac.command" --update` | `-Update` |
| 自己改的固件起不来，刷回标准版 | `bash "<技能目录>/restore-mac.command" --cqnu` | `-RestoreCqnu` |
| 换回原厂固件 | `bash "<技能目录>/restore-mac.command"` | `-RestoreFactory` |

原厂备份在 `<技能目录>/backup/factory-工牌编号.bin`。换回原厂要用它，**不要删除这个文件夹**。没有备份时，可以用 FoloToy 官网的“恢复出厂固件”教程：扫工牌背面的二维码，用电脑上的 Chrome 或 Edge 浏览器操作。

## 必须遵守

- **只用本目录里的脚本刷机。** 不要自己拼 esptool 命令，不要下载或换用其他刷机工具。
- **绝对不要运行 `espefuse`、`burn_efuse`、`burn_key`，不要开启 secure boot 或 flash encryption。** 这些操作会永久改变芯片，可能让工牌报废。
- 不要运行 `erase-flash` / `erase_flash`。
- 不要删除、覆盖 `backup/` 里的文件。
- 同一台电脑一次只插一张工牌。

## 常见问题

| 现象 | 处理 |
|---|---|
| 找不到工牌 | 换一根数据线；按键让屏幕亮着；换一个 USB 口；不要接扩展坞 |
| Mac 提示“无法验证开发者” | 脚本已自动去掉隔离标记；仍提示时，在“系统设置 → 隐私与安全性”里点“仍要打开” |
| Windows 提示“已阻止此应用” | 点“更多信息 → 仍要运行”；或者右键压缩包 → 属性 → 勾选“解除锁定”后重新解压 |
| 刷到一半失败 | 拔线、重插、让屏幕亮着，再运行一次 |
| 屏幕一直停在连 Wi-Fi | 确认是 2.4G Wi-Fi、密码对；用小程序重新配一次 |
| 连上 Wi-Fi 但一直“找不到后台” | 确认这个 Wi-Fi 能上外网（手机连同一个 Wi-Fi 打开 <后台>/healthz 试试）；不行请联系培训老师 |
| 扫码打不开表单 | 换微信或飞书扫；手机要能上网 |
