# 重师大 AI 工牌 · WorkBuddy 配置技能

装好这个技能后，WorkBuddy 会一步一步带你把工牌配置好：刷机 → 连 Wi-Fi → 扫码登记 → 收第一条消息，全程约 10 分钟。

## 安装（二选一）

**方法一：装成技能（推荐，以后升级、恢复也能用）**
1. 解压后得到 `cqnu-badge` 文件夹。
2. 把它放进 WorkBuddy 的技能目录：
   - Mac：用户文件夹下的 `.workbuddy/skills/`
   - Windows：`C:\Users\你的用户名\.workbuddy\skills\`
3. 在 WorkBuddy 里说：**帮我配置 AI 工牌**

**方法二：直接拖进对话**
把 `cqnu-badge` 文件夹拖进 WorkBuddy 对话框，说：**按这个文件夹里的 SKILL.md，一步一步带我配置 AI 工牌**

## 开始前准备

- 一根**能传数据**的 USB-C 线。
- 手机装好微信，打开蓝牙。
- 知道现场 **2.4G** Wi-Fi 的名称和密码。

## 文件夹里有什么

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 给 WorkBuddy 看的分步说明 |
| `firmware/` | 重师大固件 |
| `tools/` | 刷机工具（乐鑫官方 esptool） |
| `backup/` | 第一次刷机时自动保存的原厂固件备份。**别删** |
| `flash-*`、`restore-*` | 刷机和恢复脚本，WorkBuddy 会替你运行 |
| `server.txt` | 后台地址（第 5 步发测试消息用） |
